# ISSO 54 v5 / BRL 9501 EDR execution report — 2026-09-07

## Executive result

The supplied **ISSO 54 version 5.0** document is the current EDR test-definition document for the NTA 8800 (2025) / BRL 9501:2026 framework. It contains the test definitions and input descriptions, but it explicitly states that the numerical reference results are contained in a **separate Excel document** named `Referentiewaarden`.

Therefore:

- **Test definitions:** obtained.
- **Reference result workbook:** not obtained.
- **Current screening kernel:** executable for a small translated subset.
- **Formal EDR conformance:** **BLOCKED**.
- **No PASS claims are made.**

The document states that a calculation method is rejected when a result differs by more than **1.0%** from the applicable reference result. This makes the missing workbook the critical missing evidence for numerical EDR validation.

## Important evidence from ISSO 54 v5

Section 6 states that the outputs of the standard EDR tests and realistic buildings are in a separate Excel document, `Referentiewaarden`, and sets the acceptance criterion at ±1.0%.

Section 10 repeats the same arrangement for the Maatwerkadvies tests: the MWA reference values are in a separate Excel document, `Referentiewaarden maatwerkadvies`, with the same ±1.0% rejection criterion.

This means the PDF itself is sufficient to build the **test-input fixtures**, but not sufficient to perform the final numerical comparison required for attestation.

### Interpretation

The repeated result for EPW004a–g is **not a successful orientation test**. The current screening engine has no real orientation input and therefore cannot model the solar/orientation change specified by ISSO 54. Likewise, EPW003c currently does not implement the roller-shutter thermal/solar effect.

EPW002a and EPW002b do exercise different envelope inputs, but their numerical outputs should not be compared to the official reference values yet because the screening kernel is not the NTA 8800 calculation chain.

## Maatwerkadvies

The v5 document also contains the Maatwerkadvies EDR suite. Residential MWA has 14 tests and utility MWA has 34 tests. The residential suite includes EPW901 reference cases, EPW902/903 standard profiles, EPW904 ventilation correction, EPW905 energy carriers, EPW906 location factors, and the new EPW907 renovation-passport steps.

The document gives concrete MWA inputs that are useful for future implementation. For example, EPW901a uses a 1964 dwelling, natural ventilation A.1, an HR107 boiler with 80/60°C design temperatures, and the standard user profile with three occupants. EPW901b provides the energy-efficient variant with Rc 6 construction, HR++ glazing, D.2 balanced ventilation with WTW and LT floor heating.

The MWA section also supplies the three residential user profiles and their parameters, which gives us useful independent regression fixtures once the MWA calculation chain is implemented.

## What remains blocked

The following are still required before this repository can claim numerical EDR conformance:

1. The official `Referentiewaarden` workbook for the 322 base tests.
2. The official `Referentiewaarden maatwerkadvies` workbook for the 48 MWA tests.
3. Complete NTA 8800:2025+C1:2026 calculation implementation.
4. Input models for all applicable EPW/EPU test variants.
5. Correct orientation, shading, thermal-bridge, ground/AOR, infiltration, ventilation, distribution, generation, DHW, cooling, PV and primary-energy calculations.
6. Exact required output quantities and rounding.
7. Immutable test evidence and independent review.

## Bottom line

This is a meaningful step forward: **we now have the actual current v5 test definitions**, including the complete test inventory and Maatwerkadvies suite. But the document itself confirms that the numerical reference results are deliberately supplied separately.

The next high-value target is therefore very specific: obtain the two `Referentiewaarden` Excel workbooks. Once those are available, we can build a proper fixture runner that reports per-test numerical deviation and PASS/FAIL against the ±1.0% bands instead of merely executing screening translations.
